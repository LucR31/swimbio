Contributing
============

SWIM is an open project and contributions are welcome.


Ways to contribute
------------------

Contributions can include:

* Bug reports
* Documentation improvements
* Example datasets
* New software implementations
* Compatibility improvements
* Suggestions for the data model
* New measurement types


Specification changes
---------------------

Changes to the SWIM specification should consider:

#. Backward compatibility
#. Clear definitions
#. Units and coordinate conventions
#. Required and optional data
#. Interoperability
#. Scientific reproducibility


Before proposing a major change
-------------------------------

For substantial changes to the format, please open an issue on GitHub
before implementing the change.

This allows the implications for existing datasets and implementations
to be discussed first.
