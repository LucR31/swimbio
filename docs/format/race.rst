Race Data
=========

SWIM can store metadata describing the race or performance associated
with a dataset.


Race metadata
-------------

Race information may include:

* Event
* Distance
* Stroke
* Date
* Competition
* Heat
* Lane
* Pool information
* Timing information


Example
-------

A simplified race description might look conceptually like:

.. code-block:: text

   event: 100 m freestyle
   distance_m: 100
   stroke: freestyle
   date: 2026-06-15


Race results
------------

Race results may include official performance time, splits, laps, and
other timing-related measurements.

The exact structure and required fields are defined in the SWIM
specification.
