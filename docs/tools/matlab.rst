MATLAB
======

SWIM provides MATLAB support for reading and writing SWIM files.


Implementation
--------------

The MATLAB implementation is included in the SWIM repository.

https://github.com/LucR31/swimbio


Reading data
------------

The MATLAB implementation provides functions for accessing SWIM
datasets and metadata.


Writing data
------------

SWIM datasets can also be generated from MATLAB.


Compatibility
-------------

The MATLAB implementation operates on the HDF5 structure defined by
the SWIM specification.

Implementations should follow the SWIM specification rather than
depending on implementation-specific behavior.
